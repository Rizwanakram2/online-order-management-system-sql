# online-order-management-system-sql
The online order management system is a SQL server based database project designed to manage the complete Order process of an online shopping business. the system handle customers products categories orders payments and inventory management in organized and automated way.

in this project customers can place orders for products, and the system automatically stores order details calculates total update payment information and reduces stock quantity after each purchase. this project also include reports and views to analyize sales product performances and customer order history.
